# 页面信息架构与操作清单

本文件限定各页面主要信息、按钮位置与可执行条件。所有按钮尺寸遵循 COMPONENTS.md。
全站：页头主操作 M40，行内操作 S32，弹窗确认 M40，登录/初始化提交 L48；手机触达 ≥44。
以下是目标页面规范；按所属阶段逐步实现，不能用假数据填补尚未实现的功能。

## 1. 登录与初始化

桌面卡宽 440，最大视口减32；padding32，手机24。品牌文本、标题、说明、字段、全宽 L48 操作；字段间20。
首次账号初始化与创建公司为两个步骤。公司创建向导：基本信息→科技公司模板→模型配置/稍后配置→确认。
步骤数在页面明确；“上一步”secondary M40，“创建公司”primary L48。加载失败保留填写内容。
不得出现默认账户或硬编码密钥提示；登录错误不泄露账户是否存在。

## 2. 概览

顶部：公司名、运行状态；右侧创建项目。
第一行四个指标：进行中任务、待决策提案、已验证交付、Token 剩余额度。显示统计周期和口径；待加载为骨架，未知为“—”。
第二行左侧待处理列表，右侧预算与阻塞提示；第三行近期执行。桌面四列指标，平板两列，手机一列/两列依内容宽度。
运行状态不能做成毫无依据的“公司效率 98%”。预算红线与执行故障需要可点击查看来源。

## 3. 组织编辑器

默认层级图与列表切换；五岗位一眼可见。节点显示岗位、员工名、员工状态、运行状态、模型。
选中员工打开560抽屉：资料/职责/模型/授权摘要/履历。保存 M40 在底部右侧，取消在左。
主管变更展示影响说明，不自动改变权限；循环关系服务端拒绝并反馈字段错误。
暂停、离职在“更多”菜单 danger-text S32；离职确认必须展示待交接任务。不能直接删掉员工历史。
只读组织展示先于拖拽；拖拽不是验收必需，可访问层级列表是必需。

## 4. 模型中心

三 tabs：供应商、模型、员工分配；不能把 Agent ID 当模型 ID。
Provider 卡/表：名称、endpoint、secret 状态、最近探测、更新时间。行操作“编辑”“测试连接”S32，更多包含停用。
编辑抽屉：名称、base URL、secret 引用；主按钮“保存配置”，次按钮“测试连接”，测试不得隐式保存未确认配置。
测试前说明可能消耗 Token；运行中禁重复测试；结果显示时间、JSON 能力、错误类型和用量。一次探测通过不显示“全部能力支持”。
模型分配表：岗位、员工、当前模型、连接状态；改绑后旧执行保持历史配置。
无密钥显式“未配置”；演练标识固定显示在页面/执行详情。

## 5. 项目与任务

项目页先给明确目标与支持范围；创建表单含名称、目标、预算、运行模式。真实与演练用带说明的单选项，不能默认替换用户目标。
任务看板按业务状态分组，可切列表；筛选状态、负责人、项目、时间。行/卡内至少有负责人、最近执行、预算与阻塞原因。
任务详情保留目标、验收、执行尝试列表。每次尝试独立；切换历史尝试不改变当前状态。
新任务/重试成功后跳详情并开始跟踪；浏览器刷新仍能恢复记录。

## 6. 执行详情与产物

左侧五阶段时间线；主区 tabs：摘要、验证、代码/差异、日志、审计；右侧模型、角色、预算、开始时间。
“下载产物”仅在产物实际存在且有权限时可用；失败运行可下载诊断包但不能标为“成功交付”。
测试展示实际用例数、失败/跳过数、退出码、运行环境与时间。QA 结论与自动测试分开显示。
产物列表有文件名、类型、大小、哈希；不允许任意文件路径下载。
“重试执行”显示新增预算预留和尝试次数；可逆操作不增加无意义确认，涉及额外费用的重试必须展示额度影响。

## 7. 提案中心与决策

待我处理优先；列表列：标题、来源、风险、预估预算、责任人、状态、等待时间。
详情左侧先事实与证据，再建议方案、收益、验收；右侧审批路由、当前责任人、历史决策。
底部决策区：primary“批准提案”M40、secondary“要求补充”M40、ghost“拒绝”M40、更多“延后/升级”。拒绝表单要求原因。
高风险批准进入授权确认；预算不足时按钮禁用并在旁说明缺口和去预算页的入口。
已决定提案只读，显示谁、何时、为何及关联任务。重复操作返回已有决定，不能弹出第二份成功任务。
“已批准但执行能力未提供”显示独立阻塞提示，不显示“即将部署”。

## 8. 知识、预算、审计与设置

知识：范围、来源证据、版本、候选/已验证/过期；组织晋升有独立审批，不把自动总结直接显示为制度。
预算：上限、已用、预留、可用四个值；图形有文字；待结算不是零。未实现在线额度编辑时不展示可点击“充值”。
审计：主体、动作、对象、时间、关联执行与原因；详情展开结构化字段，脱敏后展示。不能从 UI 编辑或删除审计记录。
设置：账号/服务状态/版本/备份恢复说明；备份按钮只有真实功能实现后开放，恢复属于明确的数据操作流程。

## 9. 状态与操作矩阵

| 状态 | 用户可见主要操作 | 禁止或条件 |
|---|---|---|
| QUEUED | 查看、取消排队 | 不能下载尚不存在产物 |
| RUNNING/VERIFYING | 查看进度、申请取消 | 不允许同时启动同任务重试 |
| WAITING_INPUT | 补充资料 | 补充后由状态机校验恢复 |
| WAITING_APPROVAL | 查看提案/审批 | 仅有权主体可决策 |
| BLOCKED/INTERRUPTED | 查看原因、条件满足后重试 | 显示预算/尝试限制 |
| FAILED | 查看诊断、重试/提案 | 失败不等于没有产物 |
| SUCCEEDED | 查看验证、下载产物 | 后续改进创建新任务 |
| CANCELLED | 查看历史 | 不能在前端直接改回运行 |

公司暂停按钮 M40 secondary，点击立即阻止新调用并显示“已暂停；正在运行的调用按策略停止或收尾”；恢复按钮 primary M40。取消任务需要说明影响并确认；不能把浏览器断开当作取消。
