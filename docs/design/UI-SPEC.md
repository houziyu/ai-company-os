# UI 设计方案与视觉规范

版本 1.0｜目标：中文研发工作台｜适用八阶段全部界面。
数值源：design-tokens.json；本文件解释用途。visual-reference.html 为静态样张，不是运行产品。

## 1. 视觉目标

让用户先看清“公司在做什么、哪里需要我决定、产物是否通过验证”。采用浅色、清晰层级、适中信息密度的专业工作台。
主色蓝；白色卡片与浅灰页面；系统字体；轻边界。避免大面积渐变、玻璃效果、霓虹、无意义动画和装饰性仪表盘。
第一版只实现浅色主题；日志/代码面板可用深色局部表面，不把它当成暗色主题。

## 2. 颜色

| 语义 token | 色值 | 用途 |
|---|---|---|
| bg / surface / surfaceSubtle | #F8FAFC / #FFFFFF / #F1F5F9 | 页面、卡片、表头与次级区 |
| text / textSecondary | #0F172A / #475569 | 标题正文、辅助信息 |
| textMuted | #64748B | 白/页面背景上的次要文字；浅灰背景使用 textSecondary |
| border / controlBorder | #E2E8F0 / #64748B | 装饰分割线、需要被辨认的输入框边界 |
| primary / hover / active | #1D4ED8 / #1E40AF / #1E3A8A | 主操作、链接、选中项 |
| success / successSubtle | #15803D / #F0FDF4 | 已验证成功 |
| warning / warningSubtle | #92400E / #FFFBEB | 等待、阻塞、需要处理 |
| danger / dangerSubtle | #B91C1C / #FEF2F2 | 失败与危险动作 |
| neutral / neutralSubtle | #475569 / #F1F5F9 | 排队、取消、归档 |
| disabledBg / disabledText | #E2E8F0 / #475569 | 禁用控件底色与文字；对比 6.15:1 |

primary/success/warning/danger 实色底使用白字；对应浅色底使用对应深色字。
普通按钮“保存/创建/批准”使用蓝色，成功绿用于结果反馈；“拒绝提案”不是数据删除，使用次按钮；“删除/撤销执行”等危险操作使用红色。
风险等级独立显示“低风险/中风险/高风险”，不得把风险色与业务状态合并。
状态必须同时有中文文本，可加图标；不只靠圆点颜色。金额、Token 使用等宽数字对齐。
禁用态文字从 #64748B 调整为 #475569（2026-10-30，阶段 02）：原组合在 #E2E8F0 底上只有 3.86:1，低于规范要求的 4.5:1。禁用控件不降低整块透明度，因此文字本身必须满足对比度。

## 3. 字体、网格与间距

全局 14px/22px；字段标签 14/20 中等字重；辅助文字 12/18；分区标题 20/28；页标题 24/32；关键数字 32/40。
正文不使用低于 12px 的文字。表格正文仍为 14px。代码字体 13—14px，行高至少 20px，通过公共 CodePanel 统一。
默认系统回退字体，无需公网字体请求；如使用 Inter 必须本地提供合法字体资源。
间距只用 token 中的 4px 步进序列。行内图标与文字间距 8；字段上下 20；卡片内 24；卡片间 24；区块间 32。
标题与说明相距 8；页面标题区与正文相距 24。
圆角：控件 8、卡片 12、弹窗 16；药丸圆角只用于状态标签，不用于所有按钮。

## 4. 全局布局

桌面 ≥1280px：左侧栏 240，顶部栏 64，内容内边距 32；内容最大宽 1600，超宽屏居中。
平板 768—1279px：侧栏 72 图标模式，每项有可访问名称与提示；内容边距 24。复杂图表可在内容区横向滚动。
手机 <768px：顶部栏 56（窄屏特例，见 token 扩展），侧栏改抽屉，边距 16，主区域单列。主要按钮触达面积至少 44×44；表格用优先字段卡片或独立横向滚动区域，禁止整页溢出。
表单最大宽 640；详情主内容与侧面元信息可按 2:1 布局，空间不足变单列。
组织图需要同时提供可键盘操作的层级列表；拖拽是可选快捷操作。
卡片不能嵌套超过两层；列表页不为每行重复使用大阴影。

## 5. 导航与密度

一级导航固定：概览、组织、模型中心、项目与任务、提案中心、知识、预算、审计、设置。未进入阶段的页在开发环境展示“此阶段尚未开放”，发布时不出现可点击假功能。
侧栏项高 44；当前项 primarySubtle 底、primary 字色，左侧 3px 标识仅作增强。
顶部状态明确“运行中/公司已暂停”“已连接/连接中断”；全公司暂停固定在顶部，避免藏在菜单。
一页最多一个主操作组；表格行操作使用文本/ghost 按钮，不每行放实色主按钮。

## 6. 可访问性与反馈

普通文字对比目标 ≥4.5:1；大字可按 ≥3:1；控件必要边界与焦点目标 ≥3:1。本规范采用桌面 32px 起的点击区、移动端 44px，较 WCAG 最小目标更宽裕。
focus-visible 使用 2px focus 色描边、2px 外偏移；禁止全局 outline:none。
所有字段有持久 label，错误关联字段；工具提示不能成为唯一名称或说明。按钮加载状态提供 aria-busy，避免屏幕阅读器反复播报日志。
Tab 顺序与视觉顺序一致；弹窗焦点限制、Escape 关闭非阻塞弹窗、关闭后返回触发点。拖拽操作有按钮/表单替代。
遵守 reduced-motion；过渡 120/180/240ms，不用无限脉冲表示所有运行项。
未知指标显示“— / 尚无数据”；加载显示骨架，失败显示错误；无数据不能伪装为 0。

## 7. 实施映射

Element Plus 使用统一 theme 变量映射 primary/success/warning/danger/text/border，再以薄封装落地尺寸。库默认尺寸与本规范不同时以本规范为准，且必须在组件展示页验证；不要假设传 size=default 就是 40px。
基础组件展示页至少覆盖按钮、输入、选择、状态、表格、弹窗、抽屉、通知和空状态。此页面为开发与验收入口，可在生产关闭。
新增设计 token 需先说明场景与复用范围；不要为一个页面创建第二个主按钮规格。

## 8. 依据

颜色和尺寸是本项目设计决定。可访问性参考 [文字对比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 和 [目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)；组件主题实现参考 [Element Plus Theming](https://element-plus.org/en-US/guide/theming.html)。满足部分检查不等于宣称整个应用已通过 WCAG 认证。
