# 工程实现规范

## 命名与结构

Python snake_case、类 PascalCase；TypeScript camelCase、组件 PascalCase；目录职责清晰。标识符英文，用户文案与说明中文。
Python 类型注解；Vue 使用 script setup + TypeScript。禁止不解释的 any、吞异常、动态拼接 SQL 和生产业务中的演练数据。
共享枚举、DTO 和状态转换集中定义。前端契约从 OpenAPI 生成或经过契约测试验证，不手写第二套不同含义的状态值。
首阶段锁定 pnpm 与 Python 依赖管理方式；不得多个包管理器锁文件并存。Python 开发可用虚拟环境，产品标准运行入口为 Compose。

## API 契约

基础路径 /api/v1；REST 命令与查询分离。统一错误至少含 code、message、request_id、可选 field_errors；message 为可展示中文，内部堆栈只在脱敏服务日志。
列表分页必须有稳定排序；过滤条件可在 URL 恢复。超长列表不一次全量返回。
创建项目、提交审批、重试执行等写命令需要幂等键；相同键不同请求体返回 409。状态过期/并发编辑返回 409 并引导刷新。
前端防重复点击只是体验，数据库约束是最终保证。
权限验证覆盖对象归属与资源范围；不能只检查用户是否登录。
长任务返回任务/执行 ID，前端订阅进度；刷新后通过 ID 恢复。

## 数据与时间

UTC 持久化，API ISO 8601 带时区；前端按用户浏览器时区展示，并在时间明细标注时区。
数据库 schema 变更只经迁移，迁移测试使用 PostgreSQL，不以 SQLite 替代并发语义测试。
预算使用整数 Token；资金采用精确数值和币种，不用二进制浮点直接记账。
未知值用 null 和“未知/待结算”，不是 0。空结果、未配置、加载失败分别处理。
核心关系有外键/唯一/检查约束。任务、审批、审计、执行证据默认归档保留，不通过级联删除消失。

## 认证与输入

安全密码哈希、会话过期、注销撤销、CSRF/同源检查；按实际部署设置 Secure/HttpOnly/SameSite。生产 TLS 与本机 HTTP 配置分开说明。
浏览器只接收脱敏配置。日志字段白名单；Markdown 渲染禁用危险 HTML；模型输出先结构校验再展示。
任务路径标准化与范围校验，防符号链接/目录穿越；ZIP 下载基于已登记产物，不接收任意磁盘路径。

## 前端

基础 token 和 Element Plus theme 统一注入；不在页面散落 hex、字号、组件高度或 !important 覆盖。
AppButton 等薄封装暴露有限 variant/size；仍保留键盘焦点、aria、disabled 和 loading。
服务端数据通过统一 API 层管理，Pinia 存会话/筛选/界面状态等必要共享状态；不把数据库逻辑复制进 store。
页面必须有加载、空、错误、无权限、失联状态。SSE 断线显示“连接中断，结果可能未更新”，重连补读并校准查询。
图表/列表不显示编造的零值或随机进度；长文本可换行或提供展开/复制，不靠单行截断隐藏关键风险。

## 检查命令约定（待阶段 01 建立）

目标是提供前端 lint、typecheck、test、build 和后端 lint、typecheck、unit/integration test 入口；具体命令落实后写 README。
没有脚本时先报告“未建立”，不能复制其他仓库的检查命令假装存在。
测试资产和开发依赖不能进入生产运行镜像。测试 fixture 与真实数据卷隔离。
