# ADR-0006：供应商密钥由界面直接填写并加密保存

日期：2026-11-03  
状态：采用（用户明确要求"添加供应商时直接填写密钥"）  
影响：取代 ADR-0003 中"密钥只存环境变量名"的决定；不改变阶段范围与技术栈。

## 问题

阶段 02 的模型中心只接受**环境变量名**（`providers.secret_ref`），数据库用 CHECK 约束 `^[A-Z][A-Z0-9_]*$` 强制这一点，适配器只从进程环境解析。ADR-0003 当时明确否决了"密钥加密后入库"，理由是"需要密钥管理服务与轮换流程，超出本阶段"。

实际使用中这个限制成为主要摩擦：运维必须先改 `.env`、重启 api 容器，才能在界面里让一个供应商"可用"，而界面本身无法完成配置闭环。

## 决定

1. **密钥由界面直接填写。** 新增 `providers.secret_ciphertext`（`Text`，可空），保存 AES-256-GCM 封套 `v1.<kid>.<nonce>.<ciphertext>`。`secret_source` 取值扩为 `ENV | DB`。
2. **数据密钥只在服务端环境。** `SECRET_ENCRYPTION_KEY` 为 32 字节随机值的 base64。缺失时保存密钥被拒绝（503），**不降级为明文**；格式非法在启动时即失败。
3. **一行只有一种来源。** CHECK 约束保证 `secret_ref` 与 `secret_ciphertext` 不同时非空，且密文只出现在 `secret_source = 'DB'` 下。DB 行 `secret_ref` 为 NULL。
4. **旧配置保持可用。** 阶段 02 的 ENV 行继续按变量名解析，指纹算法不变（空串/变量名 → 相同输入），因此升级不会让既有证据失效。界面不再提供环境变量名输入；编辑旧行时只读展示来源，填入密钥即整体替换。
5. **不回显、不派生。** 响应只给 `secretSource` 与 `secretState`（`NONE / CONFIGURED / MISSING_ENV / UNDECRYPTABLE`）。审计 detail 只记录来源与是否配置，不记录长度、前后缀或任何派生值。读取时只做格式与 `kid` 比对（`can_decrypt`），真正解密只在付费调用前执行一次。
6. **指纹用密文哈希。** DB 行的凭据标识为 `db:<sha256(ciphertext)[:16]>`。换密钥即换密文，旧探测证据自动作废；哈希对象是密文而非明文，不构成离线校验预言机。JSON 载荷键名保持 `secretRef` 不变，避免历史指纹全部重算。
7. **清除即清除。** `changeSecretValue: true` 且无值时删除密钥并把来源置回 ENV、`secret_ref` 置空。适配器对显式给出的空值**不回落**到同名环境变量，否则"清除密钥"会从运维看不见的地方悄悄恢复。
8. **无法解密是独立错误。** 主密钥更换后，`SECRET_UNDECRYPTABLE` 计入本地拒绝集合：不发起请求、`call_count = 0`、不写用量、不结算预算，文案要求重新填写密钥。

## 备选与取舍

- **明文入库**：零配置，但备份、只读副本与任何能读表的人都直接拿到密钥。拒绝。
- **只存环境变量**（原方案）：安全边界最窄，但界面无法完成配置闭环，运维每次都要改部署文件并重启。用户明确要求改变这一点。
- **引入外部密钥管理服务（KMS/Vault）**：更完整的轮换与审计，但当前是单机 Compose 部署，引入外部依赖超出本阶段。保留为将来选项：`kid` 字段就是为多密钥轮换预留的。

## 兼容性与代价

- 升级为纯增量迁移，不重写任何行；ENV 行无需操作。
- **降级会删除密文。** 迁移的 `downgrade()` 在存在 DB 密钥行时**拒绝执行**并说明如何先清除，而不是静默丢弃用户唯一的一份密钥。
- **主密钥丢失或更换后，已存密钥不可恢复。** 只能重新录入。错误文案与界面状态必须直说，不能表现为"看似可用"。
- **数据库备份从此包含密文。** 只有"备份泄露 + 主密钥泄露"同时发生才构成密钥泄露；README 的安全说明已更新。
- 新增运行时依赖 `cryptography==46.0.6`，镜像需要重新构建。
- 未做密钥轮换工具：更换 `SECRET_ENCRYPTION_KEY` 会让所有 DB 行变成 `UNDECRYPTABLE`，需要逐条重填。批量重加密留待需要时实现。

## 验证

正式回归位于 `backend/tests/test_provider_secrets.py`（15 项）与 `frontend/src/__tests__/provider-secret.spec.ts`（6 项），覆盖加密存储、全表 canary 扫描、无数据密钥时拒存、换密钥后本地拒绝、省略字段保留密钥、显式清除不回退、旧 ENV 行回归、适配器优先级与密文篡改。实际结果见[验收报告](../acceptance/provider-secret-storage.md)。
